# v0.1.0-alpha.1：MIX 2S 核心交互基线

首个公开工程版本，对应已实机验证的 **test06**。目标是保存可维护、可解释、可复现和可迁移的方案；当前仍为实验性移植。

- 已验证：LCD、触摸、Phosh图形界面、屏幕键盘、Foot终端、freedreno图形上下文、2.4GHz Wi-Fi/SSH自动恢复、USB Hub键鼠、Type-C正反插及充电/Host自动切换。
- 充电：5V/no-PD；DCP输入上限1A、电池充电750mA、OTG输出500mA。实测输入约0.72–0.80A，外部表曾显示0.8–0.82A；不能据此宣称PD或快充支持。
- 待解决：5GHz认证、APSD/TCPM电流策略协调、长期电源/电量验证、中文输入法、音频、蜂窝、蓝牙、休眠及USB连接电脑后的NCM动态恢复。
- 保留内核完整性保护，1156个匹配签名模块；19个initramfs模块与5个关键驱动已实际验证CMS签名。

源码仓库包含补丁、DTS、APKBUILD、seed/有效配置、维护脚本、脱敏证据、失败方案、AGENTS工作约定和backlog。Release资产包括实际已刷入boot、内核、DTB、initramfs、模块、构建元数据、固定上游源码包、源码快照及SHA256SUMS。

**使用前先核对SHA256SUMS，并阅读docs/REPRODUCE.md、docs/DEVICE_OPERATIONS.md和docs/RECOVERY.md。** 这些资产不是完整系统安装包，不含手机rootfs、用户数据或私钥；不要直接套用到其他机型。第三方代码、发行版组件和固件保留各自许可证，见NOTICE.md。

本次整理从全新固定上游包应用公开补丁，关键驱动、配置、DTS及编译出的DTB与历史test06一致；离线重打包和签名检查通过。没有在导入时全量重编内核，也没有再次操作手机。历史二进制在建仓前构建，清单关联的是对应方案的导入提交，不伪造过去的Git构建来源。
