# 工程收件箱与后续工作

本目录专门保存聊天中提出的规划、未实现能力、偶发bug和未证实猜测。它不是可直接执行的命令队列。

- ROADMAP.md：已选择的里程碑、优先级、完成标准。
- BUGS.md：可观察的问题、证据、状态和验证方法；区分已确认、待复现、待验证。
- IDEAS.md：可选方案与尚未决策的建议。
- INBOX.md：临时信息先收下，后续整理，不让零星经验消失。
- decisions/：有长期影响的选择及理由，保留被放弃方案。

每项用稳定ID，至少包含来源日期、状态、事实/推测、下一步、完成证据。修复后保留条目并链接提交/测试，不直接删除历史。新Agent开始前读未完成项；普通工作完成后同步更新并用简短中文提交。
