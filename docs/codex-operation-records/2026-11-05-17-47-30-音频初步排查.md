# 音频初步排查与实验候选

- 时间：2026-11-05 17:47（Asia/Shanghai）。目标：让原机扬声器播放、麦克风录音，并提供图形应用进行验证。
- 复核项目 AGENTS、STATUS、RECOVERY、DEVICE_OPERATIONS、GUI 和固件审计，以及 test06 设备树和配置。SSH 实读 compatible 与 test06 相符：`/proc/asound/cards` 无声卡，`/dev/snd` 仅 timer，ADSP 设备树 status 为 disabled，sound 节点无声卡配置；CDSP、modem running 不等于 ADSP 工作。WirePlumber 与 PipeWire 可被启动，但无音频节点。
- 设备已有 polaris ADSP 固件及正确路径链接、WCD9340 和 TAS2559 驱动模块，`tas2559_uCDSP.bin` 属于设备固件包。原始 [polaris 音频设备树提案](https://lists.openwall.net/linux-kernel/2022/07/07/343) 为潜在路由提供线索，不证明当前内核和硬件组合已可用；同平台参考见 [beryllium 设备树](https://github.com/torvalds/linux/blob/master/arch/arm64/boot/dts/qcom/sdm845-xiaomi-beryllium-common.dtsi)。
- 构建实验 `kernel/experiments/audio01-adsp-wcd-prototype.patch`：只开启 ADSP 并建立 WCD9340 SLIM 播放/录音链路，不配置 TAS 功放。补丁不在正式 series 中；这是候选，不是可用音频方案。参照原机历史提案，不包含蜂窝通话链路。
- 离线核验：发行版源码包、test06 boot 和 DTB 按 Release 清单核对哈希；用相同源码和当前 DTS 快照在本机重编译基线 DTB，SHA-256 与发行版一致。候选 DTB 编译成功，警告与基线相同（仅源文件路径不同）；将候选 DTB 拼入 test06 镜像，原内核和 initramfs 保持逐字节相同，boot/newc 往返检查通过。实验镜像在本机忽略目录 `work/audio01/boot-audio01.img`，SHA-256 `67c5dbc223a9c448c4f95f0973cb55593100951ddcec62cdf009e66165249757`。没有启动、刷写、安装设备软件或采集录音。
