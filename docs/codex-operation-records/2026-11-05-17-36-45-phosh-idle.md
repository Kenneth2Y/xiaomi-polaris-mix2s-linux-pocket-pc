# Phosh 空闲行为调整

- 时间：2026-11-05 17:36（Asia/Shanghai）。
- 目标：原开发机长时间无操作时不自动黑屏或锁屏。
- 阅读：AGENTS.md、README.md、STATUS.md、REPRODUCE.md、RECOVERY.md、DEVICE_OPERATIONS.md、ROADMAP.md、BUGS.md、GUI_AUDIT.md；参考 [Phosh ScreenSaverManager](https://phosh-a673aa.pages.gitlab.gnome.org/class.ScreenSaverManager.html)。
- 设备核验：SSH 登录后 compatible 为 xiaomi,polaris、运行 test06，实际 boot 镜像长度前缀 SHA-256 与已发布 test06 一致；图形会话为 user/tty7。用户明确同意暂时信任首次连接看到的 SSH 主机密钥，指纹尚未经独立渠道核验。
- 决策：直接修改该用户的 GSettings，不安装软件包、重启或改 boot。原有效值：idle-delay 300、lock-enabled true、idle-dim true、交流电和电池 sleep-inactive-type 均为 suspend；五项均没有用户级覆盖。900 秒挂起会导致屏幕变黑，故一并关闭两种供电模式的空闲挂起。屏幕常亮会增加耗电和发热。
- 写入并回读：`org.gnome.desktop.session idle-delay` 为 `uint32 0`；`org.gnome.desktop.screensaver lock-enabled` 为 `false`；`org.gnome.settings-daemon.plugins.power idle-dim` 为 `false`，`sleep-inactive-ac-type` 和 `sleep-inactive-battery-type` 均为 `nothing`。修改后屏保状态为 inactive，DRM 显示 connected、enabled、DPMS On，背光实际值非零。这是配置与运行时状态证据，不代表已完成长时间无人操作或重启后验证；手动锁屏、登录以及其他非空闲触发事件仍可能锁屏或熄屏。
- 回退：以图形桌面同一用户依次执行以下命令，删除此次用户级覆盖并恢复发行版当前默认值。修改前默认值如上；如果发行版默认值将来变化，reset 后的值也会变化。

```sh
gsettings reset org.gnome.desktop.session idle-delay
gsettings reset org.gnome.desktop.screensaver lock-enabled
gsettings reset org.gnome.settings-daemon.plugins.power idle-dim
gsettings reset org.gnome.settings-daemon.plugins.power sleep-inactive-ac-type
gsettings reset org.gnome.settings-daemon.plugins.power sleep-inactive-battery-type
```
