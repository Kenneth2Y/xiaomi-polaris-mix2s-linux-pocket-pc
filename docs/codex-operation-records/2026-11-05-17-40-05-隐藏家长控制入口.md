# 隐藏家长控制入口

- 时间：2026-11-05 17:40（Asia/Shanghai）。
- 目标：了解 Foot 三个入口，移除不需要的家长控制程序和图标。
- 查阅：项目 AGENTS.md、GUI 历史记录，以及设备上的 desktop 文件、APK 包所有权和依赖关系。设备仍运行 test06。
- 结果：Foot、Foot Client、Foot Server 分别运行 `foot`、`footclient`、`foot --server`，均属于 foot 包。家长控制入口和程序由 malcontent 包提供，`gnome-control-center` 依赖 malcontent 和 malcontent-libs。为避免牵连系统设置，不卸载依赖；在用户目录创建同名 desktop 文件，设 `Hidden=true` 以隐藏入口，保留软件包。
- 验证：Gio 应用清单不再列出家长控制，三个 Foot 条目仍可见；未现场目视确认 Phosh 首页刷新。没有安装或卸载软件包，也没有重启。
- 回退：在手机当前用户执行 `rm ~/.local/share/applications/org.freedesktop.MalcontentControl.desktop`，然后 `update-desktop-database ~/.local/share/applications`；如首页未立即刷新，可重新登录。用户级覆盖没有更改系统原文件。
